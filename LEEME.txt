PROYECTO: AGENDA DE PELICULAS

Archivos:
- modulo_peliculas.py: funciones principales de calculo y reglas de negocio.
- consola_peliculas.py: menu interactivo por consola que delega la logica en modulo_peliculas.py.
- datos_peliculas.txt: datos iniciales de peliculas.
- cargar_peliculas.py: script independiente para verificar la lectura del archivo de datos.
- prueba_peliculas.py: suite de pruebas automatizadas para todas las funciones del modulo.

Como ejecutar:
1. Abre tu terminal o CMD en esta carpeta.
2. Para usar la aplicacion interactiva:
   python consola_peliculas.py
3. Para ejecutar la suite completa de pruebas:
   python prueba_peliculas.py
4. Para ver las peliculas cargadas desde el archivo de datos:
   python cargar_peliculas.py
